# Week 01 - Linux Basics

## Goal

Learn the most common Linux terminal commands used by system administrators.

## Topics Covered

- Terminal navigation
- Working with files and directories
- Reading files
- Creating and removing files
- Copying and moving files

## Skills Practiced

- Navigate Linux filesystem
- Manage files from terminal
- Inspect system files
- Prepare for server administration tasks

- touch
- cp

- rm
- cat
- less
- head
- tail
