# Linux Basic Commands

## Navigation

pwd - show current directory

ls - list files

cd - change directory


## File management

mkdir - create directory

touch - create file

cp - copy files

mv - move or rename files

rm - remove files


## File Reading

cat - display the contents of a file

nl - display a file with line numbers

more - view a file one page at a time

less - view a file with forward and backward navigation

head - display the first lines of the file

tail -  dispaly the last lines of a file

## Searching

which - show the location of an executable command.

whereis - locate the binary, source, and manual page of a command.

find - search for files and directories.

## Text Processing

grep - search for text matching a pattern.

wc - count lines, words, and characters in a file.


## Disk Usage

df - display available disk space on file systems.


du - show the size of files and directories.


## Performance

time - measure how long a command takes to execute.
