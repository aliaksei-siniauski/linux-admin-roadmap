# Linux Administration Roadmap

## Overview

This repository documents my journey from Linux beginner to Junior SOC Analyst.

The goal is to build strong Linux administration skills and develop practical experience with system management, troubleshooting, automation, and security monitoring.

## Topics Covered

- Linux command line
- File system operations
- Users, groups, and permissions
- Text processing and searching
- Process management
- Networking fundamentals
- Bash scripting
- System monitoring
- Log analysis
- Security fundamentals
